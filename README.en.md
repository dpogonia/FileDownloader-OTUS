# File Downloader

A Load file button and a progress bar. An OTUS study project.

## What it does

A tap starts a four-step count, one second per step. The percent grows from 0 to 100. At the end an alert says the file is downloaded. There is no network request: a timer drives the progress.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/FileDownloader-OTUS.git
cd FileDownloader-OTUS
open LargeFileDownloader.xcodeproj
```

Run the **LargeFileDownloader** scheme on an iPhone simulator. The deployment target is iOS 26.1.
