# File Downloader

Кнопка «Загрузить файл» и полоска прогресса. Учебный проект OTUS.

## Что умеет приложение

Нажатие запускает отсчёт из четырёх шагов, по секунде на шаг. Процент растёт от 0 до 100. В конце появляется сообщение, что файл загружен. Сетевого запроса нет: прогресс считает таймер.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/FileDownloader-OTUS.git
cd FileDownloader-OTUS
open LargeFileDownloader.xcodeproj
```

Запустите схему **LargeFileDownloader** на симуляторе iPhone. Цель сборки — iOS 26.1.
